# Frameworks de referencia

## Idea central

Un framework proporciona una estructura para organizar el pensamiento, las capacidades y las prioridades de seguridad.

No implementa controles por sí mismo ni reemplaza el criterio.

## Para qué sirve un framework

Puede ayudar a:

- organizar capacidades;
- ordenar procesos;
- evaluar el estado actual;
- identificar brechas;
- orientar mejoras;
- comunicar riesgo;
- crear un lenguaje común.

## NIST Cybersecurity Framework

En este módulo se trabaja con una estructura de cinco funciones:

- **Identify**
- **Protect**
- **Detect**
- **Respond**
- **Recover**

### Identify

Comprender activos, entorno, dependencias, riesgos y prioridades.

### Protect

Implementar medidas para reducir la posibilidad o el impacto de un compromiso.

### Detect

Desarrollar visibilidad y capacidad de identificar actividad relevante.

### Respond

Actuar frente a un evento o incidente.

### Recover

Restaurar capacidades y continuar operando después de un incidente.

### Contexto adicional — NIST CSF 2.0

NIST publicó **Cybersecurity Framework 2.0** en 2024.

La versión actual incorpora **Govern** y organiza el Framework Core alrededor de seis funciones concurrentes y continuas:

- **Govern**
- **Identify**
- **Protect**
- **Detect**
- **Respond**
- **Recover**

**Govern** enfatiza que la ciberseguridad debe gestionarse como riesgo empresarial e incluye aspectos como estrategia, expectativas, políticas, roles, responsabilidades y supervisión.

La estructura de cinco funciones documentada anteriormente se conserva porque refleja el enfoque trabajado en este módulo; esta actualización se incorpora como contexto adicional para mantener la referencia alineada con la versión vigente del framework.

## MITRE ATT&CK

Se utiliza como referencia para interpretar el comportamiento del adversario.

Permite pensar la defensa en función de lo que un atacante podría intentar hacer, en lugar de observar solamente indicadores aislados.

## MITRE D3FEND

Aporta una perspectiva orientada a capacidades y técnicas defensivas.

## CIS Controls

Presenta controles priorizados y accionables que ayudan a convertir objetivos generales de seguridad en medidas concretas.

## Modelos de madurez

Permiten medir la evolución de capacidades y comparar el estado actual con un estado deseado.

## Framework no significa aplicación automática

Un framework organiza el razonamiento, pero su aplicación depende del contexto.

La organización sigue necesitando decidir:

- qué riesgos son relevantes;
- qué activos son críticos;
- qué capacidad necesita;
- qué costo puede asumir;
- qué beneficio espera obtener.

## Puntos clave

- Un framework ayuda a ordenar la seguridad.
- NIST CSF aporta una estructura para pensar funciones defensivas.
- MITRE ATT&CK ayuda a leer comportamiento adversario.
- MITRE D3FEND aporta una perspectiva defensiva.
- CIS Controls prioriza acciones concretas.
- El framework guía; el contexto determina cómo aplicarlo.
