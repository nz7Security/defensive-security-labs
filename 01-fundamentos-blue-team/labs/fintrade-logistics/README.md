# Fintrade Logistics — Evaluación defensiva inicial

> Estado: ⚪ Pendiente

## Objetivo

Analizar una organización ficticia desde una perspectiva defensiva para identificar qué debe protegerse, reconocer puntos de exposición, evaluar debilidades de madurez y proponer una postura inicial de Blue Team.

## Contexto organizacional

Fintrade Logistics es una organización regional con operaciones en varios países y una fuerte dependencia de servicios digitales para coordinar:

- entregas;
- proveedores;
- facturación;
- seguimiento de órdenes.

El entorno incluye:

- infraestructura y servicios cloud;
- Microsoft 365 para correo, colaboración y almacenamiento;
- ERP accesible desde la red interna;
- portal web para clientes y proveedores;
- accesos remotos para personal administrativo y técnico;
- soporte IT parcialmente tercerizado;
- endpoints corporativos distribuidos entre oficina y trabajo remoto;
- distintos niveles de privilegio, con escasa revisión periódica de accesos.

## Hechos observados

- dos campañas de phishing afectaron a usuarios administrativos;
- se observaron inicios de sesión fuera de horario utilizando cuentas válidas;
- un recurso cloud quedó expuesto accidentalmente durante un cambio operativo;
- el crecimiento de activos fue desordenado y no existe un inventario consolidado;
- no todos los activos críticos tienen un responsable claramente asignado;
- existen alertas de seguridad, pero generan mucho ruido y poca priorización;
- no se realizan ejercicios formales de Purple Team ni validaciones periódicas de cobertura;
- la organización considera que está protegida por disponer de múltiples herramientas, pero no posee una visión clara de su madurez defensiva.

## Desafío del laboratorio

### Informe técnico

El análisis deberá responder:

- ¿Qué estamos defendiendo realmente?
- ¿Qué objetivos debería tener el Blue Team?
- ¿Qué debilidades de madurez aparecen con mayor claridad?

### Informe ejecutivo

El análisis deberá responder:

- Si solo pudieran priorizarse cinco acciones iniciales, ¿cuáles deberían ser?
- ¿Qué acción podría generar la mejor asimetría a favor de la defensa?

Los entregables se desarrollarán progresivamente a medida que avance el análisis.
