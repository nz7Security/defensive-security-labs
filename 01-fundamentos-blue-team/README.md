# 01 — Fundamentos de Blue Team

## Objetivo

Construir una base conceptual para comprender la seguridad defensiva, el rol del Blue Team y los criterios necesarios para analizar y proteger una organización.

El módulo se centra en entender el entorno antes de defenderlo, identificar activos y procesos críticos, desarrollar visibilidad, interpretar amenazas y construir capacidades de detección, respuesta y mejora continua.

- Asimetría defensiva

## Laboratorio

### Fintrade Logistics — Evaluación defensiva inicial

Caso práctico orientado a:

- identificar qué se está defendiendo realmente;
- reconocer activos y procesos críticos;
- analizar la superficie de ataque;
- detectar debilidades de madurez;
- definir objetivos del Blue Team;
- priorizar acciones defensivas;
- identificar una medida con alta asimetría a favor de la defensa.
