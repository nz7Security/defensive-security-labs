# Módulo 1 — Fundamentos de Blue Team

> Estado: 🟢 Completado

## Objetivo

Construir una base conceptual para analizar entornos desde una perspectiva defensiva y comprender cómo se relacionan arquitectura, visibilidad, riesgo, detección, respuesta, resiliencia y madurez.

## Temas principales

- arquitectura y defensa;
- fundamentos de Blue Team;
- defensa activa y pasiva;
- amenaza, vulnerabilidad y riesgo;
- asimetría defensiva;
- defensa moderna;
- superficie de ataque moderna;
- modelos de madurez;
- frameworks de referencia;
- introducción a Purple Team.
